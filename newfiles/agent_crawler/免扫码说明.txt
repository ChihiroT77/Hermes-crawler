edge_login_sync.py 使用说明（免扫码登录 MediaCrawler）
=====================================================

一、为什么要这个东西

MediaCrawler 每个平台开的是自己的浏览器身份
（browser_data\cdp_<平台>_user_data_dir），跟你桌面 Edge 完全是两个浏览器。
所以即使你桌面 Edge 一直登录着，爬虫那边还是"没登录"，只能现扫码。

二、官方那条路走不通（实测结论，别再试了）

  1. 新版 Edge 的 cookie 是 App-Bound 加密（v20），钥匙绑在 msedge.exe 和
     "原来那个 profile 路径"上。换目录、换机器都解不开。
     实测：把桌面 profile 全量复制一份（1.3GB），启动后 1759 条 cookie
     只剩 10 条，B站依旧未登录 —— Edge 自己把解不开的票全丢了。

  2. 想直接驱动你桌面 Edge（--remote-debugging-port 挂在默认 profile 上）
     会被 Edge 136+ 硬拒：端口根本不开。微软专门堵这条路。

  结论：桌面 Edge 的登录态没法用程序搬出来，这是浏览器安全设计，不是配置问题。

三、最省事：点一下扩展按钮（推荐）

  原理：扩展在浏览器内部调用官方接口要 cookie，浏览器直接给明文。
  所以不用解密、也不受新版加密的限制 —— 这不是破安全机制，是走浏览器自己开的口子。

  一次性安装（约 1 分钟，只装一次）：
    双击 agent_crawler\安装免扫码插件.bat，按窗口里的提示做完三步即可。
    （它做的事：把插件复制到一个固定位置，避免你挪动项目文件夹后插件失效；
     然后自动打开 Edge 扩展页和插件文件夹。不想用脚本也可以手动装：
     1. Edge 地址栏输入 edge://extensions 回车
     2. 打开"开发人员模式"（左下角或右侧的开关）
     3. 点"加载解压缩的扩展"，选 agent_crawler\edge_cookie_ext 这个文件夹
     4. 工具栏出现「爬虫登录票导出」图标，点拼图图标可把它固定出来）

  装好（或以后更新过）扩展要重载一次：edge://extensions → 找到本扩展 → 点"重新加载"。重载后几秒内会自动导一份（后台脚本一启动就导），工具栏图标上会短暂显示导出的条数；如果图标显示红色 !，说明导出出错。

  版本 1.8 解决的几件事（都属于"会往下载夹反复写明文"或"该导没导"）：
    - 浏览器为了省内存会随时把扩展的后台冻掉。冻掉后它记不住"上次导过"，醒来又导一份。
      1.7 起改成从下载记录里把时间找回来；1.8 起连"上次导的是哪份登录票"也一并找回来。
    - 以前任何 cookie 变化都触发导出 —— 你随便刷网页，站点会不停更新埋点那类无关 cookie，
      结果每两分钟就写一份明文。现在只盯真正代表登录状态的几条（B站的 SESSDATA、
      微博的 SUB、抖音的 sessionid 等）。
    - 兜底检查以前每 15 分钟必然写一份（时间条件反而给它开了后门）。现在登录票没变就不写文件。
    - 以前"离上次太近"会直接丢掉这次变化，刚登录完的平台要等 15 分钟才补上。现在排一个
      刚好到点的延后导出，不漏也不重复。
    - 只留最近两份的逻辑，以前因为时间比较写错，可能删掉最新的、留下最旧的。已修正。
    - 顺手修：隐藏页面用完不关（内存泄漏）、下载地址永不释放、notbilibili.com 这种假域名被
      当成 B 站、兜底闹钟每次醒来都被重置成"从现在起 15 分钟"（等于永不触发）。

  ⚠ 兼容性提示：这台机器上本扩展的 chrome.storage.local 是坏的（LevelDB 恒为 0 字节，写进去静默失败），所以 1.4 起后台不再依赖存储，状态只放内存。另外 Service Worker 里没有 URL.createObjectURL，1.5 起改用同源的隐藏页面 offscreen.html 造 blob 下载地址（失败退 data: 地址），manifest 因此多了 offscreen 权限。版本演进：1.2 全 promise + 诊断 → 1.3 启动标记 → 1.4 去掉存储依赖 → 1.5 修 createObjectURL（真凶）→ 1.6 加"正在跑就别再来"的锁 → 1.7 防冻结后重复导出 → 1.8 只盯登录票 + 指纹恢复 + 延后补导。

  排查"点了重载没反应"：edge://extensions 上点扩展卡片里的「服务工作进程」链接（它平时显示"不活动"是正常休眠，点一下会唤醒并把 console 打出来），控制台里依次应看到：后台脚本启动 x.x → 开始导出 → 读完 cookie → 拿到下载地址 → 导出成功。卡在哪一步，问题就在哪一步。

  平时怎么用 —— 全自动，你什么都不用点：
    1. 桌面 Edge 里把要采的平台登录好（B站 / 微博 / 贴吧 …）
    2. 等半分钟。扩展盯着登录状态的变化，登录完 30 秒内会自己导出一份
       mc_cookies_auto_时间戳_fp指纹.json 到"下载"文件夹；之后每 15 分钟兜底检查一次，
       但登录状态没变就不写新文件。旧文件自动删掉，只留最近两份。
    3. 直接叫我爬。爬虫开跑前发现没票，会自己去找最新那份导进去、再验一次，
       验过了就开始爬（日志里会写"发现扩展导出 → 自动导入"）

  想手动也行（自动没跟上时）：
    点扩展图标 →"全部导出（推荐）"，然后

         cd 到 MediaCrawler 项目根目录
         .venv\Scripts\python.exe agent_crawler\edge_login_sync.py --import-json all latest

    latest 表示自动用"下载"文件夹里最新那份导出文件，不用自己找路径。

  不想让爬虫自动导入就加 --no-auto-import。

  只想更新一个平台：点扩展里"只导出 XX"，然后

         .venv\Scripts\python.exe agent_crawler\edge_login_sync.py --import-json bili 文件路径

  注意：
    - 小红书、知乎默认仍然不导入（按你的要求保持登出），真要导加 --force
    - 快手：桌面 Edge 本来就没登录快手，扩展也变不出票 —— 先在桌面登录快手再点按钮，
      或者扫码一次
    - 导出的 json 里是明文登录凭据，导入完就删掉，别发给别人
    - 贴吧（百度系）走"原域名写入"：逐条照抄原来的域名/路径/属性，并先清掉旧票。
      早先把它压成一个域写进去，会让贴吧和 passport 来回 302 踢成死循环
      （ERR_TOO_MANY_REDIRECTS）。这个已经是默认行为，不用你管。

四、备选：你贴一次，我灌一次（--import）

思路：不解密、不搬家。你在 Edge 里按 F12 复制一个请求的 cookie 头，
本工具把它"翻译"成爬虫浏览器认得的形式写进去（v10 重加密 + 域名绑定），
爬虫启动时就能直接带着登录态跑。已实测：Edge 打开后读到 125 条 cookie，
访问 B 站显示"已登录 阿Chihiro"。

操作（30 秒，每个平台过期时做一次）：

  1. 用你的桌面 Edge 打开该平台并确认已登录（B站/微博/贴吧…）。
  2. F12 打开开发者工具 → Network（网络）标签 → 刷新页面 → 随便点一条
     发往该平台的请求 → 右键 → Copy → Copy as cURL（复制为 cURL）。
  3. 粘贴到一个 txt 文件里（UTF-8），存到任意位置，例如 cookies\wb.txt
  4. 执行（把 wb 换成平台名）：

     cd 到 MediaCrawler 项目根目录
     .venv\Scripts\python.exe agent_crawler\edge_login_sync.py --import wb --curl-file cookies\wb.txt

     也可以直接贴一行 cookie 头，不用存文件：
     .venv\Scripts\python.exe agent_crawler\edge_login_sync.py --import wb --cookie "SUB=xxx; SUBP=yyy"

  5. 它会先拿这票去平台接口验一次（无效就直接拒绝，不会写脏数据），
     再写进爬虫 profile，并回读比对，最后告诉你结果。
  6. 复查：.venv\Scripts\python.exe agent_crawler\edge_login_sync.py --check wb

支持的平台名：bili / wb / dy / ks / xhs / tieba / zhihu
（xhs、zhihu 按你的要求默认拦截，真要导入加 --force）

五、其它命令

  --check [平台]        实测各平台登录票是否有效（不开浏览器、不改文件）
                        结果怎么看：
                          OK ...      = 票有效，直接爬，不用扫码
                          ?  ...      = 票在，但该平台接口要签名，本机验不了真伪（抖音、小红书）
                          FAIL ...    = 爬虫里没有票或票过期 → 按第三节贴一次
                          读不到 ...  = 这个平台的浏览器正开着（多半正在跑采集），
                                        文件被独占读不了，等跑完再看；这不是登录失效
  --sync <平台>         旧路线：从桌面 Edge 搬 cookie。只有来源是 v10 老加密时才可能成功，
                        新版 Edge 会全部失败并提示"解不开" —— 正常现象，改用 --import
  --dry-run             只报告不写文件
  --close-edge          需要读桌面 Cookies 库时自动优雅关闭 Edge（不带 /F）

六、注意

  - 每次导入前自动备份目标 Cookies 库（Cookies.bak_年月日时分秒），可回滚。
  - 自动导出的文件叫 mc_cookies_auto_*.json，扩展自己轮换（只留最近两份）；每次执行的进展（开始导出 / 读完 cookie / 拿到下载地址 / 导出成功 / skip 原因 / 报错原文）都打在后台的 console 里，图标角标显示条数（失败红 !），不再写 chrome.storage（这台机器上它坏了）；
    手动导出的 mc_cookies_*.json 不会被自动删，验完自己删。
  - 扩展只用你自己浏览器里本来就有的登录状态，不额外制造身份。导出文件是明文，
    别转发给别人；确认导入成功后就把下载夹里那几份删掉，扩展下次登录变化时会再生成。
  - 导入的票一样会过期（比如 B站 SESSDATA 到期），过期后你在桌面 Edge 重新登录一次，
    扩展会自动再导一份，下次开爬自动换上，不用再扫码。
  - 快手（ks）如果你的桌面 Edge 本来就没登录，那就没票可贴，只能扫码一次。
  - 爬虫同一时间只能跑一个（共用 9222 端口）；导入时不要有爬虫在跑。
